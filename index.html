Stock AI Studio

구글 드라이브의 내 사진을 스톡 사이트에 올릴 수 있게 정리하는 개인용 도구입니다.

하는 일

  • 사용자가 지정한 구글 드라이브 폴더의 사진과 메타데이터 파일을 읽습니다.
  • 사진 규격, 제목, 키워드를 검사하고 스톡 사이트별 업로드 묶음을 만듭니다.
  • 만든 묶음과 처리 현황표를 같은 구글 드라이브 폴더에 저장합니다.

누가 쓰나요

이 도구는 운영자 한 사람이 자신의 구글 계정으로만 사용하는 개인용 프로그램입니다. 다른 사용자에게 서비스를 제공하지 않습니다.

English

Stock AI Studio is a personal tool used only by its owner. It reads photos and a metadata file from a Google Drive folder chosen by the owner, prepares upload batches for stock photo sites, and saves the results back to the same Drive folder.
