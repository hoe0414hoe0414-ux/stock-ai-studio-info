개인정보처리방침

Stock AI Studio · 시행일 2026년 11월 8일

1. 이용하는 정보

이 도구는 운영자가 직접 지정한 구글 드라이브 폴더에서 아래 정보만 이용합니다.

  • 사진 파일과 파일 이름
  • 사진별 제목, 설명, 키워드를 적은 메타데이터 파일
  • 도구가 만든 처리 기록과 결과 파일

이메일, 연락처, 결제 정보처럼 위와 관계없는 정보는 수집하지 않습니다.

2. 이용 목적

사진을 검사하고 스톡 사이트용 업로드 묶음과 현황표를 만드는 데에만 씁니다. 광고, 판매, 프로필 분석, 인공지능 모델 학습에는 쓰지 않습니다.

3. 보관과 삭제

  • 사진은 처리하는 동안만 임시 실행 서버에 내려받으며, 실행이 끝나면 서버와 함께 삭제됩니다.
  • 결과 파일과 처리 기록은 운영자의 구글 드라이브에만 저장됩니다.
  • 구글 접근 권한 정보는 암호화된 저장 공간에 보관하며 공개하지 않습니다.

4. 제3자 제공

구글 사용자 데이터를 다른 사람이나 회사에 팔거나 넘기지 않습니다. 업로드 묶음을 스톡 사이트에 올리는 일은 운영자가 직접 합니다.

5. 권한 철회

구글 계정의 서드 파티 앱 및 서비스 화면에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다.

6. 구글 API 사용 원칙

Stock AI Studio's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

English summary

Stock AI Studio is a personal tool used only by its owner. It accesses only the photos, metadata file, and result files in a Google Drive folder chosen by the owner, and uses them only to prepare stock photo upload batches. It does not sell, share, or use Google user data for advertising or AI model training. Photos are downloaded only to a temporary server during processing and deleted when the run ends. Access can be revoked at any time from the Google Account connections page.
